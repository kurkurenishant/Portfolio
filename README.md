## 💻 Section 4: Featured Technical Projects

### 1. LexiSpace 3D | NLP Tokenizer & 3D Word Embedding Visualizer
- **Repository:** [`https://github.com/kurkurenishant/LLM-pipeline-expoler`](https://github.com/kurkurenishant/LLM-pipeline-expoler)
- **Problem Statement:** Modern Large Language Models represent text tokens as dense mathematical vectors in high-dimensional geometric spaces, but students and engineers struggle to visualize how tokenizers (Word, Subword/BPE, Character), token ID dictionaries, and spatial cosine similarities operate under the hood.
- **Solution Architecture:** Constructed an interactive educational client-side dashboard featuring multi-strategy tokenization, an automated vocabulary builder with persistent `localStorage`, and an interactive 3D word embedding coordinate space built with **Three.js** and **OrbitControls**. Calculates real-time cosine similarity threshold links between word nodes, supports direct 3D node dragging, and renders dynamic HTML5 canvas billboard sprite labels with 2D PCA projection toggling.
- **Tech Stack:** Vanilla JavaScript (ES6+), Three.js, OrbitControls, Chart.js, Lucide Icons, Tailwind CSS, LocalStorage API.
- **Individual Contribution:** 100% Solo Project — Designed the subword BPE simulation algorithms, Three.js 3D vector scene, mathematical cosine similarity computation, and responsive UI.

### 2. Perplexity Explorer | In-Browser Causal Language Model & Perplexity Visualizer
- **Repository:** [`https://github.com/kurkurenishant/perpelxity_explorer`](https://github.com/kurkurenishant/perpelxity_explorer)
- **Problem Statement:** Understanding how autoregressive causal language models predict tokens, evaluate probability distributions, and quantify sequence perplexity is usually obscured behind server-side cloud APIs or complex Python ML environments.
- **Solution Architecture:** Built a zero-build client-side playground executing **Transformers.js v3** with an 8-bit quantized ONNX model (`Xenova/distilgpt2`) entirely locally in the browser. Features an interactive Sentence Lab with BPE token segmentation, a Token Inspector displaying candidate probabilities, real-time cross-entropy loss computation, and fluency contrast benchmarks.
- **Tech Stack:** JavaScript (ES6+), Transformers.js v3, ONNX Runtime Web, Xenova/distilgpt2 (q8), Tailwind CSS, Canvas.
- **Individual Contribution:** 100% Solo Project — Implemented the browser ONNX model pipeline, cross-entropy mathematical routines, probability visualizers, and zero-dependency packaging.

### 3. Mini Google 1998 | PageRank Random Surfer Simulation & Search Engine
- **Repository:** [`https://github.com/kurkurenishant/Mini-Google`](https://github.com/kurkurenishant/Mini-Google)
- **Problem Statement:** Early search engines based exclusively on keyword frequency were vulnerable to term manipulation, creating a need to demonstrate how PageRank revolutionized search by treating the web as a directed graph.
- **Solution Architecture:** Engineered a retro 1998 Google interface contrasting 1997 Keyword Frequency ranking directly against 1998 PageRank. Implemented a 100,000-iteration Monte Carlo Random Surfer algorithm with damping factor across a multi-node web graph, inverted indexing, text normalization, and search result snippet generation with highlighted matching terms.
- **Tech Stack:** Pure JavaScript, Semantic HTML5, CSS3, Graph Algorithms (Random Walk, Inverted Indexing).
- **Individual Contribution:** 100% Solo Project — Developed the Monte Carlo Random Surfer algorithm, graph link matrix, and side-by-side comparative ranking display.

### 4. Groq Playground | Ultra-Low Latency LLM Workbench
- **Repository:** [`https://github.com/kurkurenishant/groq-playgorund`](https://github.com/kurkurenishant/groq-playgorund)
- **Problem Statement:** Developers and researchers require an instant, real-time playground to evaluate streaming response latencies, test prompt variants, and benchmark tokens/second across various state-of-the-art open-weight models.
- **Solution Architecture:** Architected a high-performance developer workbench integrating Groq's LPU inference API via Server-Sent Events (SSE). Measures real-time token generation velocity, time-to-first-token (TTFT) latency, temperature/top-p controls, and dynamic model switching (LLaMA 3, Mixtral, Gemma).
- **Tech Stack:** JavaScript, Groq Cloud API, Fetch/Stream API, Tailwind CSS, Responsive Design.
- **Individual Contribution:** 100% Solo Project — Designed streaming SSE client parser, latency calculation metrics, and parameter control interface.
