## 💻 Local Development & Quick Start

Running the portfolio locally requires no external package installations.

### Option A: Python Built-in HTTP Server (Recommended)
```bash
# Clone the repository
git clone https://github.com/kurkurenishant/Portfolio.git

# Navigate into the project
cd Portfolio

# Start local server on port 3000
python3 -m http.server 3000
```
Open **`http://localhost:3000`** in your browser.

### Option B: Node.js / npx serve
```bash
npx serve . -l 3000
```

### Option C: Direct File Inspection
Simply open `index.html` in your browser:
```bash
open index.html
```

## 🌐 Automated GitHub Pages Deployment

The repository includes a GitHub Actions workflow in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

### To activate GitHub Pages on your repository:
1. Go to your GitHub repository: [github.com/kurkurenishant/Portfolio](https://github.com/kurkurenishant/Portfolio).
2. Click **Settings** &rarr; **Pages** (under the "Code and automation" section).
3. Under **Build and deployment** &rarr; **Source**, select **GitHub Actions**.
4. Push your changes to `main`. The workflow will trigger automatically and publish your site at:
   ```
   https://kurkurenishant.github.io/Portfolio/
   ```
